# 천문학의 세계 퀴즈

2026학년도 2학기 「천문학의 세계」 중간고사(10/21) 대비 퀴즈 사이트. 교안(통합본)·수업 녹취 13회(9/2~10/19 정리 수업)·학생 필기본을 바탕으로 만든 예상문제 117문항을 7개 단원(주제)으로 나눠 풀 수 있다.

10/20 개정: 10/19 정리 수업에서 「시험 문제는 객관식이 아닙니다. 단답형입니다」라고 해서 보기 고르기 12문항을 모두 단답형으로 바꾸고, 정리 수업에서 짚은 내용으로 17문항(긴 서술 2 포함)을 더했다. 해설에 10/19 발언과 필기본 메모를 덧붙였다.

- **시작하기** → 주제를 골라 한 문항씩 풀고, 바로 정답·해설·근거(교안 쪽, 필기본 쪽, 녹취 시각)를 본다. 「문항 순서 섞기」를 켜면 문항 순서가 섞인다.
- **오답노트(기록보관소)** → 틀린 문항과 부분 정답 서술형이 주제별로 쌓인다. 내 답·정답·해설을 다시 보고, 오답만 모아 다시 풀 수 있다. 다시 맞혀도 지우지 않고 「다시 맞힘」으로 표시한다.
- 기록은 이 브라우저(localStorage, 키 `astro26:v1`)에만 저장된다. 다른 기기·브라우저와는 공유되지 않고, 브라우저 데이터를 지우면 사라진다.

키보드: `1`~`5` 보기 선택, `Enter` 다음 문제(단답형 빈칸에서는 다음 칸 → 제출), 서술형은 `Ctrl`+`Enter`로 제출(`Enter`는 줄바꿈).

## 문항 유형과 채점

| 유형 | 문항 수 | 채점 |
| --- | --- | --- |
| 단답형 | 89 | 빈칸마다 허용 표현과 비교 |
| 서술형 | 28 | 필수 키워드 규칙(아래) |

보기 고르기(하나 고르기·모두 고르기) 화면은 앱에 남아 있지만 10/20 개정 뒤로는 그런 문항이 없다.

**단답형**: 입력과 허용 표현을 똑같이 정규화(소문자, 공백·`,·()「」'"` 제거, 위·아래첨자 숫자 → 숫자, `×`·`*`→`x`, `^` 제거, `−`→`-`, 숫자 사이 `-`·`∼`→`~`, 천 단위 쉼표 제거)한 뒤, 같거나 허용 표현(2글자 이상)을 포함하면 정답이다. 숫자는 소수점을 지우지 않고, 허용 표현의 앞뒤 숫자가 입력에서 다른 숫자에 붙어 있으면 맞힌 것으로 보지 않는다(`26`은 `3.26`에 맞지 않고, `3.26`·`3.26광년`·`약 3.26`은 맞다). `!`로 시작하는 허용 표현이 들어 있으면 오답(예: 「신성」 칸에 「초신성」). 순서가 바뀌어도 되는 빈칸은 화면에 안내한다.

**서술형**: 문항마다 채점 기준(rubric)이 있다.

```json
"rubric": {
  "keywords": [
    {"label": "황도(공전 궤도면)", "any": ["황도", "공전궤도면", "ecliptic"]},
    {"label": "하지·동지", "any": ["하지", "동지"], "not": ["하지만", "하지않"]}
  ],
  "min": 2
}
```

- `keywords` 하나가 개념 하나다. `any`의 표현 중 하나라도 답안에 들어 있으면 그 키워드를 맞힌 것으로 본다(단답형과 같은 정규화 뒤 포함 비교).
- `not`은 부분 문자열 때문에 반대 뜻이 맞는 일을 막는다. 답안에서 `not` 표현을 먼저 지운 뒤 `any`를 찾으므로, 그 표현으로만 맞는 경우는 인정하지 않는다(예: 「하지만」의 「하지」).
- `min`은 정답에 필요한 키워드 수로, 없으면 키워드 전부다.
- 키워드가 `min` 이상이면 **정답**, 1개 이상이지만 모자라면 **부분 정답(맞힌 수/전체)** — 점수는 0점이고 오답노트에 남는다, 0개면 **오답**. 키워드마다 ✓/✗ 칩, 모범답안, 해설·근거를 보여 준다.
- 자동 채점이 놓친 표현은 「내 답도 맞아요 — 정답으로 처리」로 바로잡을 수 있다(단답형·서술형).
